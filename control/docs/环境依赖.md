# 环境依赖

## 必需依赖

| 依赖 | 用途 | 说明 |
|------|------|------|
| Bash | 执行安装、检查、测试脚本 | macOS / Linux / WSL 均可 |
| Git | 版本管理、diff、审查 | 强烈建议目标项目先 `git init` |
| Codex App 或 Codex CLI | 主控 Agent | 负责需求、架构、实现、测试和审查 |

## 推荐依赖

| 依赖 | 用途 |
|------|------|
| ripgrep (`rg`) | 快速搜索代码和文档 |
| Docker | 启动 MySQL、Redis、依赖服务 |
| curl | deepv4 OpenAI-compatible API 调用 |
| Node.js | deepv4 脚本安全生成 JSON |
| OpenSpec CLI | 官方 `openspec` 命令和 slash command，可选 |

## 前端常见依赖

| 技术 | 用途 |

| pnpm / npm | 包管理 |

## 项目测试配置

项目画像写在：

```text
.ai-control/project.env
.ai-control/project-profile.md
```

本机覆盖测试命令写在：

```text
.agent/project.env
```

示例：

```bash
PROJECT_TEST_COMMAND='cd api && ./mvnw test && cd ../vue && pnpm build'
```

## deepv4 可选依赖

deepv4 通过 OpenAI-compatible API 接入，配置写在：

```text
.agent/deepv4.env
```

小白优先运行：

```bash
bash .ai-control/control/scripts/ai-dev.sh init
```

按提示启用 deepv4 并输入 `DEEPV4_BASE_URL`、`DEEPV4_API_KEY`、`DEEPV4_MODEL` 即可。

示例：

```bash
DEEPV4_BASE_URL='https://api.example.com/v1'
DEEPV4_API_KEY='replace-with-your-key'
DEEPV4_MODEL='deepv4'
DEEPV4_REVIEW_COMMAND='bash .ai-control/control/scripts/providers/deepv4-openai-compatible.sh'
```

真实 key 不要提交到 git。

## OpenSpec CLI 可选依赖

本控制系统已经自带 `openspec/` 目录模板和 `.ai-control/control/scripts/openspec-*.sh` 检查脚本。只使用 `.ai-control/control/scripts/ai-dev.sh` 时，不要求安装官方 OpenSpec CLI。

如果你希望额外使用官方 `openspec` 命令、slash command 或官方校验能力，可以安装：

```bash
npm install -g @fission-ai/openspec@latest
```

检查：

```bash
openspec --version
```

新项目如果要使用官方 OpenSpec CLI，可以在接入控制系统前先运行：

```bash
openspec init
```

已经安装本控制系统的项目，不建议盲目再次运行 `openspec init`。它可能生成或修改 `openspec/`、`AGENTS.md` 等文件。确实要运行时，先提交或备份当前改动，再看 `git diff` 决定是否保留。

## 支持的项目形态

| 项目形态 | 支持情况 |
|----------|----------|
| Java / Spring Boot / MySQL | 优先支持 |
| Vue / React 管理端 | 支持通用前端流程 |
| api + vue monorepo | 支持 |
| Go / Gin | 支持通用后端流程，读取 `.ai-control/control/docs/stacks/GO_GIN.md` |
| PHP / Laravel / ThinkPHP | 支持通用后端流程，读取 `.ai-control/control/docs/stacks/PHP.md` |
| gupo 项目 | 通过 gupo profile 支持专用 adapter |

## 不会自动做的事

- 不自动安装 JDK、Node、Maven、Docker。
- 不自动创建数据库。
- 不自动执行迁移 SQL。
- 不自动调用 deepv4，除非你配置并运行脚本。
- 不强制安装官方 OpenSpec CLI；需要官方 `openspec` 命令时再安装。
