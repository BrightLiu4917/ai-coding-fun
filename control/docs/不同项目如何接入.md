# 不同项目如何接入

## 推荐方式

默认使用自动识别：

```bash
bash control/scripts/bootstrap-new-project.sh --project-dir /path/to/project
```

脚本会根据 `pom.xml`、`package.json`、`go.mod`、`composer.json`、Docker 文件和依赖内容推荐 profile。

## Profile 选择

| profile | 适合项目 |
|---------|----------|
| `auto` | 自动识别，推荐默认使用 |
| `fullstack-admin` | Spring Boot + Vue/React 后台系统 |
| `java-springboot` | Java / Spring Boot 后端 |
| `vue3-admin` | Vue3 管理端 |
| `react-admin` | React 管理端 |
| `go-gin` | Go / Gin 后端 |
| `php` | PHP / Laravel / ThinkPHP 后端 |
| `minimal` | 只要最小 OpenSpec、agent、docs、templates |
| `default` | 通用完整安装 |
| `gupo` | 仅 gupo 专用项目使用 |

## 常见项目

### Spring Boot + Vue3

```bash
bash control/scripts/bootstrap-new-project.sh \
  --project-dir /path/to/project \
  --profile fullstack-admin \
  --backend api \
  --frontend vue
```

### 纯 Spring Boot

```bash
bash control/scripts/bootstrap-new-project.sh \
  --project-dir /path/to/project \
  --profile java-springboot
```

### 纯 Vue3

```bash
bash control/scripts/bootstrap-new-project.sh \
  --project-dir /path/to/project \
  --profile vue3-admin
```

### Go / Gin

```bash
bash control/scripts/bootstrap-new-project.sh \
  --project-dir /path/to/project \
  --profile go-gin
```

### PHP

```bash
bash control/scripts/bootstrap-new-project.sh \
  --project-dir /path/to/project \
  --profile php
```

## 接入原则

- 目标项目已有约定优先。
- `.ai-control/project.env` 是项目适配层，不是业务事实。
- OpenSpec 才是需求、设计、任务和规格事实源。
- 不同技术栈只读取对应 `.ai-control/control/docs/stacks/` 规则。
- JWT、RBAC、CRUD、OpenAPI 这类能力读取 `.ai-control/control/docs/features/` 规则。
