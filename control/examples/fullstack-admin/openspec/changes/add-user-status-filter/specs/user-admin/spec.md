# 用户管理规格变更

## 新增需求

### 需求：用户列表应支持按已确认状态筛选
系统必须允许运营人员在用户列表中选择已确认的用户状态进行筛选。

#### 场景：按状态筛选用户
- 前置条件：运营人员拥有用户列表查看权限。
- 当：运营人员选择一个用户状态。
- 则：列表只展示匹配该状态的用户。
- 并且：分页信息与筛选结果一致。

### 需求：状态筛选不得发明枚举值
系统必须从后端事实源或已确认规格读取状态选项。

#### 场景：状态选项加载
- 前置条件：用户列表页需要展示状态筛选。
- 当：页面加载状态选项。
- 则：状态值来自已确认来源。
- 并且：前端不得硬编码未确认状态。
