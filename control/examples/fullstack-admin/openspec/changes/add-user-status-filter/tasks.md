# 任务清单

## 规格确认
- [ ] 确认用户状态枚举来源。
- [ ] 确认用户列表接口是否已有 `status` 参数。
- [ ] 确认状态选项是否受权限或租户影响。
- [ ] 确认后台用户列表访问控制模式、权限点和无权限返回。

## 实现任务
- [ ] 通过 开发工程师（`agent-dev`）审查筛选流程、空态和错误态。
- [ ] 通过 产品规格工程师（`agent-spec`）审查 API 契约。
- [ ] 通过发布审查工程师（`agent-release`）审查访问控制和越权场景。
- [ ] 实现前端筛选控件和状态同步。
- [ ] 必要时实现后端状态选项接口或列表筛选。

## 验证任务
- [ ] 默认进入列表不改变原结果。
- [ ] 选择状态后只展示匹配用户。
- [ ] 清空筛选后恢复默认列表。
- [ ] 状态选项加载失败有错误态和重试。
- [ ] 无权限场景不暴露不可见状态。
