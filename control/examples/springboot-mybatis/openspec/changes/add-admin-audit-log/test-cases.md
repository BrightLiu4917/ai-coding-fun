# 测试用例

> 设计阶段由测试工程师产出，随 change 一起确认；验收以 JUnit 报告和交付说明为证据。

## 用例清单

| 用例ID | 关联场景 | 类型 | 前置条件 | 步骤 | 预期结果 | 验证方式 |
|--------|----------|------|----------|------|----------|----------|
| TC-01 | 审计日志分页查询 | 正常流 | 存在多条审计日志 | 调用 `GET /api/admin/v1/audit-log/page` | 按时间倒序分页返回，字段完整 | 集成 |
| TC-02 | 非法分页参数 | 异常流 | 已登录管理员 | 以 `pageSize=-1` 请求 | 返回参数错误，不返回 500 | 单测 |
| TC-03 | 无权限访问 | 权限 | 使用无审计日志权限的账号 | 请求分页接口 | 返回无权限响应 | 集成 |
| TC-04 | 大数据量分页 | 边界 | 日志量超过一页上限 | 请求最后一页 | 分页计数正确，无重复数据 | 集成 |
| TC-05 | 写操作产生日志 | 正常流 | 执行一次后台写操作 | 查询审计日志 | 新日志落库，操作人和租户字段正确 | 集成 |

- 类型：正常流 / 异常流 / 权限 / 边界 / 兼容性 / 并发
- 验证方式：单测 / 集成 / E2E / 手动

## 测试命令

```bash
bash .ai-control/control/scripts/run-tests.sh
```
