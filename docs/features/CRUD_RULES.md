# CRUD 功能规则

## 适用范围

适用于管理端列表、新增、编辑、详情、删除、启停、审核等标准维护功能。

## 默认边界

- CRUD 不等于无脑生成，字段、状态、权限、删除行为和审计要求必须确认。
- 标准 CRUD 脚手架只能生成预览或骨架，真实业务实现必须结合目标项目约定调整。
- 数据库内部可保留 `pk_id`，API 对外统一暴露 `id`。
- 前端长 ID 一律字符串处理。

## 必须确认

- 是否软删除。
- 是否有租户或数据范围。
- 是否有唯一约束。
- 是否需要状态流。
- 是否需要导入、导出、批量操作。
- 是否需要操作日志。
- 访问控制模式是什么：本服务 RBAC、外部权限服务、网关/IAM/SSO 或不适用。
- 是否需要权限点、菜单权限、按钮权限和数据范围。
